## Conexiones de Pantallas OLED
**Pantalla izquierda**
GND -> GND

VCC -> VCC

D0 -> PB7(PIN 8)

D1 -> PB5(PIN 6)

RES -> PB3(PIN 4)

DC -> PB2(PIN 3)

SC -> PB0(PIN 1) Diferencia con la otra pantalla
**Pantalla derecha**
GND -> GND

VCC -> VCC

D0 -> PB7(PIN 8)

D1 -> PB5(PIN 6)

RES -> PB3(PIN 4)

DC -> PB2(PIN 3)

SC -> PB1(PIN 2) Diferencia con la otra pantalla
